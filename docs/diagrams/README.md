# Diagram sources

- [system-flow.mmd](system-flow.mmd): Mermaid source for the system map.
- [file-journey.mmd](file-journey.mmd): Mermaid source for intake, classification and verified persistence.
- [memory-loop.mmd](memory-loop.mmd): Mermaid source for shared-memory continuity.
- [os-system-flow.html](os-system-flow.html): editable inline visualization fragment used in ChatGPT. It relies on the host's theme variables and tab runtime; it is not a standalone hosted application.

The [repository README](../../README.md) renders the high-level map directly in GitHub. The deployment PDF contains a static wiring diagram. All diagrams describe the target architecture, not currently deployed services.

To publish the interactive diagram outside its original host, wrap it as a standalone page with theme styles and tab behavior and verify it in a real browser. Do not treat a raw fragment opened from GitHub as a deployed UI.
